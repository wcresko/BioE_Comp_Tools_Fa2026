10.1 Why Python, Too?

Chapter 9 introduced R, the language this book uses for statistics, tidy data, and graphics. Python is the other language you will meet constantly in bioengineering. It is a general-purpose language created by Guido van Rossum in 1991, and over the past fifteen years it has become the default language for machine learning, image analysis, instrument control, and much of bioinformatics tooling. If a colleague in an engineering lab hands you code, it is more likely to be Python than R.

The good news is that almost everything you learned in R transfers. Variables, vectors, data frames, functions, loops, reading files, and plotting all exist in Python under slightly different names, and this chapter is organized to follow Chapter 9 section by section so you can map one onto the other. The chapter ends with a translation table (Table 10.4) that you can keep open while you work.

TipOne running example

As in Chapter 9, we use a small gene-expression experiment (five samples, two drugs, one response measurement) and a handful of DNA sequences whose GC content we compute. Every section reuses these so that you can concentrate on the syntax rather than the data.

Like R, Python is an interpreted language: you type an expression and see the result immediately. Unlike R, Python was not designed for statistics, so numerical arrays (NumPy), data frames (pandas), and plotting (matplotlib, seaborn) all live in add-on packages that you install and import. Base Python is small and general; the scientific stack sits on top of it.

10.2 Installing Python

There are several ways to get Python 3, and in Chapter 2 you probably already used the first. Which one you choose matters less than using one of them consistently.

python.org installer. Download from https://www.python.org/downloads/. On Windows, check “Add python.exe to PATH” during installation. This gives you a single system-wide Python plus pip, the package installer.

uv. A fast, modern tool from Astral that installs Python versions, creates environments, and installs packages, all with one command-line program. Install it once, then uv python install 3.12 fetches an interpreter. It is the quickest route on macOS and Linux.

conda (Miniconda or Miniforge). A package manager that installs Python and non-Python software (samtools, R, compilers) into isolated environments. It is heavier than venv but is the standard on HPC systems and in bioinformatics.

On Talapas. Nothing to install: use the module system described in Chapter 20.

module avail python          # list available Python modules
module load python3          # load the default Python 3
python3 --version
# Python 3.12.3

Check whichever installation you have:

python3 --version            # Python 3.12.x
python3 -m pip --version     # pip 24.x from ...
Warningpython vs python3

On many systems python is either missing or points to an old Python 2. Always type python3 at the shell (and #!/usr/bin/env python3 in scripts) unless you are inside an activated environment, where python is safe. On Windows outside WSL the launcher is py.

10.3 Virtual Environments

R users install packages once into a library and load them with library(). Python users go one step further: each project gets its own virtual environment, a private folder holding a copy of the interpreter’s links and every package the project needs. This prevents the situation where upgrading pandas for one analysis silently breaks another. Section 2.10 introduced the idea; here is the full workflow.

# Create an environment in the project folder (do this once)
python3 -m venv .venv

# Activate it (every time you open a new terminal)
source .venv/bin/activate          # macOS, Linux, WSL
# .venv\Scripts\activate           # Windows PowerShell

# Install packages into it
pip install numpy pandas matplotlib seaborn

# Record exactly what is installed, for reproducibility
pip freeze > requirements.txt

# Later, on another machine:
pip install -r requirements.txt

# Leave the environment
deactivate

With uv the same steps are shorter and much faster:

uv venv                            # creates .venv
source .venv/bin/activate
uv pip install numpy pandas matplotlib seaborn

With conda, environments live in a central location rather than in the project folder, and can include non-Python tools:

conda create -n rnaseq python=3.12 pandas matplotlib samtools
conda activate rnaseq
conda env export > environment.yml      # the conda equivalent of requirements.txt
conda deactivate
Tip

Add .venv/ to your .gitignore (Chapter 19). Commit requirements.txt or environment.yml instead; anyone can rebuild the environment from that file.

10.4 Running Python Code

Python offers the same console-versus-script choice as R, plus notebooks.

The REPL. Type python3 at the shell to get the interactive prompt (>>>). Type an expression, see the result, and exit() when done. In Positron and VS Code, the Python console is the same thing with a nicer interface.

Scripts. Save code in a .py file and run it with python3 script.py. To make it directly executable, add a shebang and set the permission bit, exactly as for a shell script (Chapter 8):

#!/usr/bin/env python3
# hello.py - my first Python script

print("Hello, Bioengineering!")
chmod +x hello.py
./hello.py
# Hello, Bioengineering!

Jupyter notebooks. pip install jupyter then jupyter lab opens a browser-based notebook in which code cells and Markdown cells alternate and outputs are saved in the .ipynb file. Notebooks are excellent for exploration and are what you will get on Talapas through Open OnDemand.

Quarto chunks. In a .qmd file a {python} chunk runs through Jupyter when the document renders (Chapter 16):

```{python}
#| label: gc-demo
seq = "ATGCGCGATATCG"
gc = (seq.count("G") + seq.count("C")) / len(seq)
print(f"GC content: {gc:.2f}")
```
Note

In this chapter the Python chunks are shown with their expected output as trailing # comments rather than executed at render time, so that the book builds on a machine with R alone.

10.5 Python Basics: Types, Arithmetic, and Variables

Arithmetic

4 * 4                # 16
(4 + 3 * 2**2)       # 16   (** is exponentiation, not ^)
17 // 5              # 3    integer division  (R: 17 %/% 5)
17 % 5               # 2    modulo            (R: 17 %% 5)
7 / 2                # 3.5  (true division; / never truncates in Python 3)

import math
math.sqrt(144) + math.log(100)   # 16.605170185988092

Note that ^ is not exponentiation in Python (it is bitwise XOR), and that the mathematical functions live in the math module.

Variables and Assignment

Assignment uses =; there is no <-. Names follow the same rules as R (letters, digits, underscores; case-sensitive; cannot start with a digit), and the convention is snake_case.

x = 2
y = 5
z = x * y
z                    # 10

# Multiple assignment in one line
n_samples, n_genes = 5, 20000

Basic Types

Table 10.1 lists the basic types with their R equivalents (compare Table 9.2).

type(42)             # <class 'int'>
type(3.14)           # <class 'float'>
type("hello")        # <class 'str'>
type(True)           # <class 'bool'>

# Conversion
int("42")            # 42
float("3.5")         # 3.5
str(123)             # '123'
bool(0)              # False
bool(1)              # True

Comparisons and Logical Operators

Comparison operators are the same as R. Logical operators are spelled out as words:

5 > 3                # True
5 == 5               # True
5 != 3               # True

True and False       # False   (R: &&)
True or False        # True    (R: ||)
not True             # False   (R: !)

"TP53" in ["BRCA1", "TP53", "EGFR"]   # True    (R: %in%)

# Floating point is the same everywhere
0.1 + 0.2 == 0.3                       # False
math.isclose(0.1 + 0.2, 0.3)           # True    (R: all.equal / near)

10.6 Strings and f-strings

Strings are first-class in Python and carry many methods. Indexing is 0-based, and slicing s[start:stop] excludes stop.

seq = "ATGCGCGATATCG"

len(seq)             # 13
seq[0]               # 'A'      first character (R: substr(seq, 1, 1))
seq[-1]              # 'G'      last character
seq[0:3]             # 'ATG'    characters 0, 1, 2
seq[3:]              # 'CGCGATATCG'

seq.count("G")       # 4
seq.lower()          # 'atgcgcgatatcg'
seq.replace("T", "U")            # 'AUGCGCGAUAUCG'
seq.startswith("ATG")            # True
"gene,sample,value".split(",")   # ['gene', 'sample', 'value']
"_".join(["S1", "control"])      # 'S1_control'
"  padded  ".strip()             # 'padded'

f-strings put values inside text with {} and optional format specifications. They replace paste()/sprintf() from R:

gene = "TP53"
gc = (seq.count("G") + seq.count("C")) / len(seq)

print(f"{gene}: GC content = {gc:.3f}")
# TP53: GC content = 0.538

print(f"{gene:<8}{len(seq):>6} bp")     # left/right alignment
# TP53         13 bp

10.7 Lists, Tuples, Dictionaries, and Sets

Python’s built-in containers do the work of R’s vectors and lists, but note that a Python list is more like an R list() than like a vector: it can hold mixed types, and arithmetic does not apply element-wise (that is NumPy’s job, Section 10.8). Table 10.2 compares the four containers.

Lists

measurements = [2, 3, 4, 2, 1, 2, 4, 5, 10, 8, 9]
samples = ["control", "treatment_A", "treatment_B"]

measurements[0]          # 2        (R: measurements[1])
measurements[-1]         # 9        last element
measurements[1:4]        # [3, 4, 2]
len(measurements)        # 11

samples.append("treatment_C")     # add to end (modifies in place)
samples.sort()                    # sorts in place
sorted(measurements, reverse=True)   # returns a new sorted list

sum(measurements)        # 50
max(measurements)        # 10
measurements.index(10)   # 8   position of the value 10

A list comprehension applies an expression to every element, taking the place of sapply()/purrr::map() and of many for loops:

[x * 2 for x in measurements]            # [4, 6, 8, 4, 2, 4, 8, 10, 20, 16, 18]
[x for x in measurements if x > 5]       # [10, 8, 9]     (R: x[x > 5])
[s.upper() for s in samples]             # ['CONTROL', 'TREATMENT_A', ...]

Tuples

point = (3.2, 5.1)
point[0]                 # 3.2
x, y = point             # unpacking

# Functions that return several values return a tuple
def min_max(values):
    return min(values), max(values)

lo, hi = min_max(measurements)   # lo = 1, hi = 10

Dictionaries

A dictionary maps keys to values and is the closest thing to an R named list or named vector:

expression = {"BRCA1": 5.2, "TP53": 8.1, "EGFR": 3.4}

expression["TP53"]               # 8.1
expression["KRAS"] = 9.7         # add a key
"EGFR" in expression             # True
expression.get("MYC", 0.0)       # 0.0  default when key is missing

list(expression.keys())          # ['BRCA1', 'TP53', 'EGFR', 'KRAS']
list(expression.values())        # [5.2, 8.1, 3.4, 9.7]

for gene, value in expression.items():
    print(f"{gene}: {value}")
# BRCA1: 5.2
# TP53: 8.1
# ...

Sets

genes = {"BRCA1", "TP53", "EGFR", "KRAS"}
targets = {"TP53", "EGFR", "MYC"}

genes & targets          # {'TP53', 'EGFR'}          intersection (R: intersect)
genes | targets          # union                     (R: union)
genes - targets          # {'BRCA1', 'KRAS'}         difference   (R: setdiff)
len(set([1, 1, 2, 3]))   # 3                         (R: length(unique(x)))

10.8 NumPy Arrays

NumPy provides the n-dimensional array, the object that makes Python behave like R’s vectors and matrices: same-type elements, element-wise arithmetic, and fast numerical routines. Import it as np by convention.

import numpy as np

x = np.array([2, 3, 4, 2, 1, 2, 4, 5, 10, 8, 9])

x * 2                    # array([ 4,  6,  8,  4,  2,  4,  8, 10, 20, 16, 18])
x ** 2                   # element-wise square
np.log(x)                # element-wise log
x + np.arange(1, 12)     # element-wise addition of two arrays

x.mean(), x.std(ddof=1)  # (4.545..., 3.045...)   ddof=1 gives R's sample sd
np.median(x)             # 4.0
x[x > 5]                 # array([10,  8,  9])   logical indexing, as in R
np.where(x > 5)          # (array([8, 9, 10]),)  (R: which(x > 5), but 0-based)

# Sequences (R: seq, rep)
np.arange(0, 10, 0.5)              # 0, 0.5, ..., 9.5
np.linspace(0, 1, 5)               # array([0.  , 0.25, 0.5 , 0.75, 1.  ])
np.repeat(["A", "B"], 3)           # ['A','A','A','B','B','B']

# Matrices (R: matrix)
mat = np.arange(1, 13).reshape(3, 4)
mat.shape                # (3, 4)
mat[0, 1]                # 2      row 0, column 1
mat[:, 2]                # third column
mat.T                    # transpose
mat.sum(axis=0)          # column sums (R: apply(mat, 2, sum))
mat.sum(axis=1)          # row sums    (R: apply(mat, 1, sum))
Important

NumPy’s std() and var() divide by n by default (population), whereas R’s sd() and var() divide by n − 1 (sample). Pass ddof=1 to match R. pandas’ .std() uses ddof=1 by default, so it already matches R.

Missing values in NumPy are np.nan (a float), and like R’s NA they propagate unless you ask for the NaN-aware versions:

v = np.array([1.0, 2.0, np.nan, 4.0])
v.mean()                 # nan
np.nanmean(v)            # 2.333...   (R: mean(v, na.rm = TRUE))
np.isnan(v)              # array([False, False,  True, False])

10.9 Control Flow

Python uses indentation instead of braces to mark blocks. Four spaces per level is the universal convention; a colon ends the line that opens a block.

score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
grade                    # 'B'

# for loops iterate directly over any collection
for sample in ["S1", "S2", "S3"]:
    print(sample)

# range() gives integer sequences (0-based, stop excluded)
for i in range(5):
    print(i ** 2)        # 0 1 4 9 16

# enumerate() gives index and value together
for i, gene in enumerate(["BRCA1", "TP53"]):
    print(i, gene)       # 0 BRCA1 / 1 TP53

# zip() walks two sequences in parallel (R: mapply / map2)
for gene, value in zip(["BRCA1", "TP53"], [5.2, 8.1]):
    print(f"{gene}={value}")

# while loops, break and continue as in bash and R
n = 0
while n < 3:
    n += 1
    if n == 2:
        continue
    print(n)             # 1 3

A vectorized conditional (R’s ifelse()) is np.where():

scores = np.array([85, 72, 91, 68, 79])
np.where(scores >= 80, "Pass", "Fail")
# array(['Pass', 'Fail', 'Pass', 'Fail', 'Fail'], dtype='<U4')

10.10 Functions

Functions are defined with def. The body is indented, and return sends a value back; a function with no return returns None. Defaults, keyword arguments, and positional matching work as in R.

def gc_content(seq, digits=3):
    """Return the GC fraction of a DNA sequence.

    Parameters
    ----------
    seq : str
        DNA sequence (case-insensitive).
    digits : int, optional
        Number of decimal places to round to.
    """
    seq = seq.upper()
    gc = seq.count("G") + seq.count("C")
    return round(gc / len(seq), digits)

gc_content("ATGCGCGATATCG")             # 0.538
gc_content("atgcgc", digits=1)          # 0.7
gc_content(digits=2, seq="GGCC")        # 1.0   named arguments in any order

The triple-quoted string right after def is the docstring, Python’s built-in documentation. help(gc_content) prints it, exactly as ?mean does in R, and IDEs show it on hover. Write one for every function you expect to reuse (Chapter 13 covers function design in R; the same principles apply).

Type hints annotate the expected types. Python does not enforce them, but editors and AI assistants (Chapter 18) use them to catch mistakes and to complete your code:

def calculate_cv(values: list[float]) -> float:
    """Coefficient of variation as a percentage."""
    arr = np.asarray(values)
    return float(arr.std(ddof=1) / arr.mean() * 100)

calculate_cv([10, 12, 11, 13, 9, 14])   # 16.66...

Small anonymous functions use lambda, the equivalent of R’s \(x):

sorted(["BRCA1", "TP53", "EGFR"], key=lambda g: len(g))   # ['TP53', 'EGFR', 'BRCA1']

10.11 Reading and Writing Files

pathlib.Path represents file paths portably; open() opens a file and the with block closes it automatically when you are done.

from pathlib import Path

data_dir = Path("data")
fasta = data_dir / "sequences.fasta"     # / joins path components
fasta.exists()                           # True
fasta.suffix                             # '.fasta'
list(data_dir.glob("*.csv"))             # all CSV files in data/

# Read a whole file as one string, or line by line
text = fasta.read_text()

with open(fasta) as fh:
    n_records = sum(1 for line in fh if line.startswith(">"))
print(n_records)                         # 3

# Write text
Path("results.txt").write_text(f"{n_records} records\n")

with open("log.txt", "a") as fh:         # "a" appends; "w" overwrites
    fh.write("finished\n")

A minimal FASTA parser using only built-ins:

def read_fasta(path):
    """Return a dict mapping sequence names to sequences."""
    seqs = {}
    name = None
    with open(path) as fh:
        for line in fh:
            line = line.strip()
            if line.startswith(">"):
                name = line[1:].split()[0]
                seqs[name] = ""
            elif name:
                seqs[name] += line
    return seqs

for name, seq in read_fasta("data/sequences.fasta").items():
    print(f"{name}\t{len(seq)}\t{gc_content(seq)}")
# seq1    60    0.483
# seq2    72    0.611
# seq3    45    0.400

The csv module handles quoting and delimiters for you when you need row-by-row access; for anything tabular, though, pandas (Section 10.12) is easier.

import csv

with open("data/experiment.csv", newline="") as fh:
    for row in csv.DictReader(fh):
        print(row["sample_id"], float(row["response"]))

with open("out.tsv", "w", newline="") as fh:
    writer = csv.writer(fh, delimiter="\t")
    writer.writerow(["gene", "gc"])
    writer.writerow(["seq1", 0.483])

10.12 pandas DataFrames

pandas is Python’s data-frame library, and its DataFrame plays the role of R’s data.frame/tibble. If you know dplyr (Chapter 11), you already know what each method does; Table 10.3 lists the correspondences.

Creating and Inspecting

import pandas as pd

experiment = pd.DataFrame({
    "sample_id":     ["S1", "S2", "S3", "S4", "S5"],
    "treatment":     ["control", "drug_A", "drug_A", "drug_B", "drug_B"],
    "concentration": [0, 10, 20, 10, 20],
    "response":      [1.2, 3.4, 5.6, 2.8, 4.1],
})

experiment
#   sample_id treatment  concentration  response
# 0        S1   control              0       1.2
# 1        S2    drug_A             10       3.4
# 2        S3    drug_A             20       5.6
# 3        S4    drug_B             10       2.8
# 4        S5    drug_B             20       4.1

experiment.shape           # (5, 4)        (R: dim)
experiment.columns         # Index(['sample_id', ...])   (R: names)
experiment.dtypes          # column types  (R: str)
experiment.head(3)         # first rows
experiment.describe()      # summary statistics (R: summary)
experiment.info()          # structure overview

Reading and Writing

df = pd.read_csv("data/experiment.csv")                 # R: read.csv / read_csv
df = pd.read_csv("data/counts.tsv", sep="\t")           # tab-separated
df = pd.read_csv("data.csv", na_values=["", "NA", "N/A"])
df = pd.read_excel("data.xlsx")                          # needs openpyxl

experiment.to_csv("results.csv", index=False)            # index=False drops the row numbers
experiment.to_csv("results.tsv", sep="\t", index=False)

Selecting and Filtering

experiment["response"]                     # one column -> Series (R: df$response)
experiment[["sample_id", "response"]]      # several columns -> DataFrame
experiment.loc[0]                          # row by label
experiment.iloc[0:3]                       # rows by position (0-based)
experiment.loc[0:2, ["treatment", "response"]]

# Filtering rows (R: filter / df[df$response > 3, ])
experiment[experiment["response"] > 3]
experiment.query("treatment == 'drug_A' and response > 3")
experiment[experiment["treatment"].isin(["drug_A", "drug_B"])]

Adding Columns, Sorting, Grouping

# mutate: add or transform columns (assign returns a new frame)
experiment = experiment.assign(
    log_response = np.log(experiment["response"]),
    replicate    = [1, 1, 2, 1, 2],
)
experiment["high"] = experiment["response"] > 3         # or assign directly

# arrange
experiment.sort_values("response", ascending=False)
experiment.sort_values(["treatment", "response"])

# group_by + summarise
experiment.groupby("treatment")["response"].mean()
# treatment
# control    1.20
# drug_A     4.50
# drug_B     3.45

experiment.groupby("treatment").agg(
    n            = ("response", "size"),
    mean_resp    = ("response", "mean"),
    sd_resp      = ("response", "std"),
).reset_index()
#   treatment  n  mean_resp   sd_resp
# 0   control  1       1.20       NaN
# 1    drug_A  2       4.50  1.555635
# 2    drug_B  2       3.45  0.919239

# count
experiment["treatment"].value_counts()

Merging and Chaining

doses = pd.DataFrame({
    "treatment": ["control", "drug_A", "drug_B"],
    "target":    ["none", "EGFR", "BRAF"],
})

merged = experiment.merge(doses, on="treatment", how="left")    # R: left_join

# Method chaining is the pandas equivalent of the pipe |>
summary = (
    experiment
    .query("concentration > 0")
    .assign(log_response=lambda d: np.log(d["response"]))
    .groupby("treatment", as_index=False)
    .agg(mean_log=("log_response", "mean"))
    .sort_values("mean_log", ascending=False)
)

Table 10.3 translates the dplyr verbs of Section 11.10 into pandas.

Missing values in pandas are NaN (or pd.NA), and df.isna(), df.dropna(), and df.fillna(0) correspond to is.na(), drop_na(), and replace_na().

10.13 Plotting with matplotlib and seaborn

matplotlib is the foundational plotting library, analogous to base R graphics; seaborn sits on top of it with data-frame-aware, statistically minded functions that feel closer to ggplot2. If you love ggplot2, the plotnine package is a faithful port of the grammar of graphics to Python (from plotnine import ggplot, aes, geom_point) and is worth a look.

seaborn works directly from a DataFrame, with x=, y=, and hue= playing the part of aes():

Many further plot types follow the same pattern: sns.histplot, sns.violinplot, sns.lineplot, sns.heatmap, and sns.pairplot. Chapter 12 explains the design principles that apply whichever library you use.

10.14 Command-Line Scripts

A Python script becomes a reusable tool once it reads its inputs from the command line, exactly as a shell script uses $1 (Section 8.7) and an R script uses commandArgs() (Section 8.10). The simplest approach is sys.argv, a list whose first element is the script name:

#!/usr/bin/env python3
# count_fasta.py - count records in a FASTA file
import sys

if len(sys.argv) < 2:
    sys.exit("Usage: count_fasta.py <file.fasta>")

path = sys.argv[1]
with open(path) as fh:
    n = sum(1 for line in fh if line.startswith(">"))
print(f"{path}: {n} records")
chmod +x count_fasta.py
./count_fasta.py data/sequences.fasta
# data/sequences.fasta: 3 records

For anything with options, argparse builds the parser, generates --help, and validates types:

#!/usr/bin/env python3
# gc_stats.py - GC content for every record in a FASTA file
import argparse
from pathlib import Path

parser = argparse.ArgumentParser(description="GC content per FASTA record")
parser.add_argument("fasta", type=Path, help="input FASTA file")
parser.add_argument("-o", "--output", type=Path, default=None,
                    help="write a TSV here instead of stdout")
parser.add_argument("--min-length", type=int, default=0,
                    help="skip sequences shorter than this")
args = parser.parse_args()

rows = [(name, len(seq), gc_content(seq))
        for name, seq in read_fasta(args.fasta).items()
        if len(seq) >= args.min_length]

out = "\n".join(f"{n}\t{l}\t{g}" for n, l, g in rows) + "\n"
if args.output:
    args.output.write_text(out)
else:
    print(out, end="")
./gc_stats.py --help
./gc_stats.py data/sequences.fasta --min-length 50 -o gc.tsv

The idiom if __name__ == "__main__": at the bottom of a script lets the same file be both imported as a module (to reuse gc_content() elsewhere) and run as a program. Scripts like these are exactly what you submit to Slurm on Talapas (Chapter 20) inside a shell wrapper.

10.15 Error Handling

Python raises exceptions when something goes wrong; a try/except block catches them so that your script can report a clear message or recover, the counterpart of R’s tryCatch() (see also Section 14.7 for purrr’s safely()).

try:
    df = pd.read_csv("data/missing.csv")
except FileNotFoundError:
    print("Input file not found; check the path")

# Catch several, and always run cleanup
try:
    value = float("abc")
except (ValueError, TypeError) as err:
    print(f"Could not convert: {err}")
finally:
    print("done")
# Could not convert: could not convert string to float: 'abc'
# done

# Raise your own errors when inputs are invalid (R: stop())
def gc_content_checked(seq):
    if not seq:
        raise ValueError("sequence is empty")
    return gc_content(seq)

Common exceptions you will meet: FileNotFoundError, KeyError (missing dictionary key or column), IndexError (position out of range), TypeError, ValueError, and ZeroDivisionError. Reading the last line of a traceback tells you which one occurred; the lines above it show where.

10.17 Summary

This chapter introduced Python 3 as a second language alongside R:

  • Install Python from python.org, uv, or conda; on Talapas, module load python3
  • Every project gets a virtual environment (python3 -m venv .venv, uv venv, or conda create), and requirements.txt or environment.yml records it
  • Run code from the REPL, python3 script.py (with #!/usr/bin/env python3), Jupyter, or {python} chunks in Quarto
  • Assignment is =, indexing is 0-based, ** is exponentiation, and blocks are marked by indentation
  • Strings have many methods and f-strings format output; lists, tuples, dicts, and sets are the built-in containers
  • NumPy arrays give R-style vectorized arithmetic; remember ddof=1 for the sample standard deviation
  • Functions use def, defaults, docstrings, and optional type hints; lambda makes small anonymous functions
  • pathlib, open(), and csv handle files; pandas handles tables with read_csv, boolean masks, assign, groupby/agg, merge, and sort_values
  • matplotlib and seaborn make figures; plotnine ports ggplot2
  • sys.argv and argparse turn scripts into command-line tools; try/except handles errors
  • Table 10.4 maps R idioms onto Python ones
