Reading materials and tools

  • The online course book, Foundational Computational Tools for Bioengineers, is the primary reading. The table below lists the chapters to read for each week; the same links appear on the Lectures page and on the first slide of every lecture.

Additional resources

  • Bioinformatics Data Skills. 2015. Vince Buffalo. O’Reilly.
  • See the Resources page for the course book, cheat sheets, and more.

Tools

  • You will be working on your own laptop computer
  • A Unix shell: Terminal on macOS/Linux, or WSL/Ubuntu on Windows (see the Software page)
  • Latest versions of R and Python
  • An editor/IDE: VS Code or Positron (RStudio is fine too)
  • Quarto with TinyTeX for rendering documents and LaTeX math
  • Git installed and a GitHub account
  • An ssh client for connecting to the UO computing cluster (Talapas) - built into every shell above
