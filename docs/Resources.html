Resources

The lectures cover each topic briefly; the appendices go deeper.

Free books and tutorials

The command line

  • Software Carpentry - The Unix Shell - the classic hands-on introduction
  • The Missing Semester of Your CS Education (MIT) - shell, scripting, editors, Git, and more
  • Buffalo, V. (2015). Bioinformatics Data Skills. O’Reilly - command-line data skills for biologists

R and Python

  • Wickham, Çetinkaya-Rundel & Grolemund. R for Data Science (2e) - the standard free book for modern R
  • Wickham et al. ggplot2: Elegant Graphics for Data Analysis
  • Wickham. Advanced R - for when you want to know how R really works
  • Software Carpentry - Programming with R and Programming with Python
  • VanderPlas. Python Data Science Handbook
  • Bioconductor - the R package repository for genomics and high-throughput biology (install with BiocManager::install()), with vignettes and workflows for each package
  • Quick-R - short base-R recipes for data input, manipulation, and basic graphics

Reproducibility, Git, and Quarto

  • Chacon & Straub. Pro Git - everything about Git, free online
  • Bryan. Happy Git and GitHub for the useR - Git for R users
  • Software Carpentry - Version Control with Git
  • GitHub Skills - short interactive GitHub courses
  • Quarto documentation and Publishing to GitHub Pages
  • The Turing Way - a community handbook for reproducible, ethical data science

Public data repositories

A short list - see the book’s Data Formats & Public Repositories appendix for what each holds and how to choose.

  • NCBI - GEO (expression data), SRA (raw reads), GenBank (sequences)
  • EMBL-EBI / ENA - the European mirror of sequence archives
  • Ensembl and UCSC Genome Browser - reference genomes and annotations
  • Protein Data Bank (RCSB PDB) - 3D structures of proteins and nucleic acids
  • Zenodo, Dryad, and Figshare - general-purpose data archives with DOIs

Getting help

  • Ask early. Office hours are Tuesday 3:00 - 4:00 in the KC Connector - or email to set up a time.
  • Read the error message - then paste it into a search engine (or a UO-supported AI assistant, using only green data).
  • Built-in help: man command in the shell, ?function in R, help(function) in Python.
  • Stack Overflow (the [r] and [python] tags) and Posit Community - most questions have already been asked and answered; when you get an error, paste it into a search engine - someone else has had the same problem.
