F.6 Control Flow and Functions

# if / elif / else — blocks are marked by indentation, not braces
if x > 10:
    label = "high"
elif x > 5:
    label = "mid"
else:
    label = "low"

# for and while; break and continue
for i in range(5):
    if i == 3:
        continue
    print(i)

while n > 0:
    n -= 1

# Functions: defaults, docstring, type hints, multiple returns
def gc_content(seq: str, digits: int = 3) -> float:
    """Return the GC fraction of a DNA sequence."""
    seq = seq.upper()
    return round((seq.count("G") + seq.count("C")) / len(seq), digits)

def min_max(x):
    return min(x), max(x)          # returns a tuple
lo, hi = min_max(values)

# Anonymous functions
sorted(genes, key=lambda g: len(g))

# Errors
try:
    df = pd.read_csv(path)
except FileNotFoundError as err:
    print(f"Missing file: {err}")
finally:
    print("done")

if not seq:
    raise ValueError("sequence is empty")

F.9 Command-Line Scripts

#!/usr/bin/env python3
import sys
import argparse

sys.argv                 # ['script.py', 'arg1', 'arg2']; sys.argv[0] is the script name
sys.exit("message")      # print to stderr and exit with status 1

parser = argparse.ArgumentParser(description="What this script does")
parser.add_argument("input", help="input file")
parser.add_argument("-o", "--output", default="out.tsv")
parser.add_argument("--min-length", type=int, default=0)
parser.add_argument("--verbose", action="store_true")
args = parser.parse_args()
args.input, args.output, args.min_length

if __name__ == "__main__":
    main()               # run only when executed, not when imported

F.11 Common Gotchas

WarningThings that bite R users
  • 0-indexing and half-open slices. x[0] is the first element, x[-1] is the last, and x[1:3] gives elements 1 and 2 only.
  • Indentation is syntax. Mixed tabs and spaces, or a missing colon before an indented block, produce IndentationError or SyntaxError. Use four spaces.
  • ^ is not power. Use **; 2 ^ 3 is 1 (bitwise XOR).
  • Lists are not vectors. [1, 2] * 2 is [1, 2, 1, 2]; use NumPy arrays for element-wise math.
  • Mutability. y = x for a list or DataFrame makes y another name for the same object; changing one changes both. Use x.copy().
  • Population vs. sample SD. np.std(x) divides by n; use ddof=1 (or pandas .std()) to match R’s sd().
  • and/or vs &/|. Words for scalars; symbols (with parentheses) for arrays and DataFrame masks.
  • NaN != NaN. Test missing values with np.isnan() or pd.isna(), never == np.nan.
  • Which Python? If import pandas fails in the IDE but works in the terminal, the IDE is using a different interpreter or environment; check the interpreter picker.
