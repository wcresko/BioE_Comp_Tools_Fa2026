E.12 Control Flow

Conditionals

# if-else
if (condition) {
  # code if TRUE
} else if (other_condition) {
  # code if other TRUE
} else {
  # code if all FALSE
}

# Vectorized if-else
ifelse(condition, value_if_true, value_if_false)

# dplyr case_when
case_when(
  condition1 ~ value1,
  condition2 ~ value2,
  TRUE ~ default_value
)

Loops

# for loop
for (i in 1:10) {
  print(i)
}

# while loop
while (condition) {
  # code
}

# break leaves the loop; next skips to the next iteration
for (i in 1:10) {
  if (i == 3) next
  if (i > 5) break
  print(i)
}

# Apply functions (preferred)
apply(m, 1, sum)         # Over matrix rows (2 = columns)
lapply(list, function)   # Returns list
sapply(list, function)   # Returns vector
vapply(x, f, numeric(1)) # Type-safe sapply
tapply(x, group, mean)   # Apply within groups
map(list, function)      # purrr, returns list
map_dbl(list, function)  # purrr, returns double vector
map_chr(x, toupper)      # purrr, character vector
map2_dbl(x, y, ~ .x + .y)          # Two inputs in parallel
map_dfr(files, read_tsv, .id = "source")   # Row-bind results into one tibble

Writing Functions

cv <- function(x, na.rm = TRUE) {
  sd(x, na.rm = na.rm) / mean(x, na.rm = na.rm) * 100
}
cv(c(4, 9, 12, 5))            # Positional argument
cv(x = c(4, 9, 12, 5))        # Named argument

safe_log <- function(x) {
  if (any(x <= 0)) return(NA)  # Explicit return() for an early exit
  log(x)
}

E.14 Common Gotchas

WarningThings that bite everyone
  • 1-indexing. R counts from 1, and x[-1] drops the first element (it does not mean “the last” as in Python).
  • = vs ==. = assigns or names an argument; == tests equality. Using = where you meant == is a silent logic bug.
  • NA propagates. mean(c(1, NA, 3)) is NA; add na.rm = TRUE to ignore missing values.
  • Strings vs. factors. Older data.frame() code coerced text to factors; tibbles and R 4.0+ do not. If a character column behaves oddly, check its class().
  • Floating-point equality. 0.1 + 0.2 == 0.3 is FALSE; compare with all.equal() or dplyr::near(), never ==, on decimals.
  • & vs &&. Use &/| on vectors (element-wise filtering) and &&/|| on single values inside if().
  • Recycling. Operating on vectors of different lengths silently recycles the shorter one; a warning appears only if the lengths are not multiples. Check length() when results look wrong.
  • Stale sessions. A package you just installed, or an object you deleted, may still be “there” in the running session. Restart R (Ctrl/Cmd + Shift + F10) before assuming something is broken (Section 2.13).
